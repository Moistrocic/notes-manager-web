fix: anchor the openlist ignore rule so server sources are committed

The unanchored "openlist/" pattern also matched server/src/openlist/, so the
OpenList API client never made it into the repository. A fresh clone therefore
failed to compile with TS2307 (Cannot find module '../openlist/client.js').

- .gitignore: anchor the reference clone, data/, tmp/ and .npm-cache/ to the
  repository root so they cannot shadow files elsewhere in the tree
- scripts/check-repo-files.mjs: new guard that fails when a source file on disk
  is missing from the repository, wired up as "npm run check:repo"
